# nannostudios.github.io

Website for **Nanno Studios**, served by GitHub Pages. Plain HTML/CSS, no build step.

| File | Purpose |
|---|---|
| `index.html` | Studio home page |
| `privacy-policy.html` | Privacy policy for every Nanno game (link this in Play Console + AdMob) |
| `app-ads.txt` | AdMob authorised sellers file. **Must stay at the site root** |
| `404.html` | Not-found page |
| `.nojekyll` | Tells Pages to serve files as-is |

Preview locally: `python -m http.server 8000` then open http://localhost:8000
